# Coin Tarayıcı

Binance USDT paritelerini 4 zaman diliminde (tüm zamanlar, 1 yıl, 1 ay, 1 gün) kurallarla puanlar.
GitHub Actions 4 saatte bir `scanner.py` çalıştırır, sonucu `docs/data.json` dosyasına yazar,
`docs/index.html` bu veriyi GitHub Pages üzerinde gösterir.

Kurulum: repoyu oluştur, dosyaları yükle, Settings > Pages > main / docs seç,
Actions sekmesinden "scan" iş akışını bir kez elle çalıştır.

Yatırım tavsiyesi değildir.
